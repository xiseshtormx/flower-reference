# Референс цветочного

Рабочая локальная версия цветочного сайта на Astro + React + Node.js + SQLite.
Публичный каталог и закрытая панель управления находятся в одном проекте.

Начните с [START-WORKING-SITE.md](START-WORKING-SITE.md): перенос файлов, создание доступа, запуск и первый тестовый заказ.

## Быстрый запуск

Node.js 24.13+:

```sh
npm install
npm run setup
npm run dev
```

Сайт: [http://localhost:4321](http://localhost:4321). Панель: [http://localhost:4321/admin](http://localhost:4321/admin).

Восемь демонстрационных букетов добавляются при первом открытии базы. Дальше ассортимент управляется через панель, `src/data/products.ts` служит только начальным набором.

## Устройство

- `src/server/` — база, права доступа, проверка товаров и заявок, изображения, очередь уведомлений.
- `src/pages/api/[...path].ts` — публичный каталог/приём заявок и закрытый API панели.
- `src/components/admin/` — управление ассортиментом, заявками и расписанием.
- `src/lib/availability.ts` — единые правила дат и времени для интерфейса и сервера.
- `src/lib/catalog-client.ts` — получение актуального каталога и отправка форм.
- `scripts/` — создание доступа, запуск сборки и резервное копирование.
- `storage/` — локальные данные, исключённые из Git и архива исходников.

Цены считает сервер, история заказов хранит снимок исходного состава и стоимости. Идемпотентный ключ защищает повторную отправку того же запроса. Изменения ассортимента сразу доступны в динамических страницах; повторная сборка для нового букета не нужна.

## Проверка

```sh
npm run check
npm test
npm run build
npm run test:integration
node tests/setup-smoke.mjs
```

Сборка и HTTP-проверки выполнены. Графический прогон интерфейса в браузере в этой среде не выполнялся.

По умолчанию активен учебный режим. Публичного размещения и онлайн-оплаты пока нет. Уведомления Telegram работают после добавления собственного токена и ID чата в `.env`.
