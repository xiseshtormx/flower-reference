# Исправление Could not import ../styles/footer.css

CSS подвала теперь находится прямо внутри SiteFooter.astro. Отдельный footer.css не используется.

1. Остановите dev-сервер через Ctrl+C.
2. Скопируйте папку src из архива в корень проекта flower-reference с объединением папок и заменой файлов. Будут заменены:
   - src/components/SiteFooter.astro
   - src/components/FooterGarden.astro
3. В папке проекта выполните npm run dev.
4. Откройте адрес из терминала и обновите страницу через Ctrl+F5.

Заново устанавливать зависимости не нужно. Если старый src/styles/footer.css уже есть, он не мешает: новый компонент его не импортирует.

Дизайн и анимация подвала сохранены. Сборка всех 11 страниц проверена при отсутствии отдельного footer.css. В итоговом HTML всех страниц присутствуют встроенные стили подвала.
