# Подвал: небольшой ботанический сад

Обновление предназначено для последней версии «Референс цветочного» (версия 2). Изменены только общий подвал и его подключение.

## Перенос

1. Остановите dev-сервер через Ctrl+C.
2. Если сами меняли src/layouts/BaseLayout.astro, сохраните его копию перед заменой.
3. Скопируйте папку src из архива в корень существующего flower-reference, объединив папки и заменив файлы. Важно перенести все три файла:
   - src/layouts/BaseLayout.astro
   - src/components/SiteFooter.astro
   - src/components/FooterGarden.astro
4. Запустите npm run dev и откройте адрес из терминала. Обновите вкладку через Ctrl+F5.

Стили встроены в SiteFooter.astro через <style is:inline>. Отдельный footer.css больше не нужен. Зависимости не менялись. npm install не нужен.

## Что изменено

Крупный верхний призыв заменён компактной композицией: небольшой заголовок «Цветы рядом», переход в каталог и две колонки ссылок. Сохранён тёмный оливковый фон. Повторяющиеся подписи мастерской и пустой блок контактов убраны, информация о демонстрационном характере проекта осталась в нижней строке.

Рядом с навигацией — тонкий векторный рисунок цветка и двух веточек. Светлая зелень и приглушённые сиреневые лепестки поддерживают общий стиль. На телефоне рисунок обрезается до центрального цветка, боковые веточки скрыты. Рисунок не располагается под ссылками, не перехватывает нажатия и скрыт от скринридера.

Используется существующая анимация однократной прорисовки при появлении блока. Нового скрипта и библиотек нет. При prefers-reduced-motion эффект отключён; без JavaScript рисунок остаётся видимым.

## Проверка

Сборка 11 страниц проходит. Проверены ссылки подвала и наличие CSS/рисунка на всех страницах. Сам SVG визуально проверен в широком и узком формате. Внешний вид полного подвала и клики в браузере рабочего окружения проверить не удалось — после переноса стоит посмотреть компьютерную и мобильную версии.
