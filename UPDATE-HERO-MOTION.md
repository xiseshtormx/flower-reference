# Обновление hero: раскрытие букета и ботанический рисунок

## Установка

1. Остановите dev-сервер через Ctrl+C.
2. Распакуйте архив flower-hero-motion-v1.zip в отдельную папку.
3. Скопируйте его папку src в корень вашего проекта flower-reference с объединением папок и заменой файлов. Не удаляйте существующую src.
4. В корне проекта выполните npm run dev.
5. Откройте адрес из терминала и обновите страницу через Ctrl+F5, находясь наверху страницы.

В обновлении три файла:
- src/components/Hero.astro — компонент, разметка и встроенные стили.
- src/components/HeroBotanical.astro — отдельный SVG цветка для первого экрана.
- src/scripts/hero-motion.ts — сценарий анимации.

Перенесите все три файла. Зависимости устанавливать заново не нужно. Отдельного hero.css нет.

## Поведение

Фотография раскрывается сверху вниз за 850 мс (600 мс на узком экране), постепенно возвращаясь к обычному масштабу. Заголовок появляется двумя целыми строками. Описание, действия, палитры и подпись товара появляются вместе; ссылки не блокируются анимацией.

На широком экране стебель, листья и лепестки прорисовываются в заданном порядке. Затем рисунок один раз слегка покачивается. Общая анимация других рисунков страницы его не затрагивает. Постоянных циклов нет.

При прокрутке фотография сдвигается внутри рамки до 18 px, тонкая рамка — в противоположную сторону до 6 px. На узком экране цветок скрыт, прокрутка не двигает изображение.

Настройка prefers-reduced-motion отключает появление, покачивание, параллакс и увеличение при наведении. При изменении настройки активные эффекты отменяются. Контент остаётся видимым без JavaScript. Восстановление страницы с уже прокрученной позиции не проигрывает вступление.

Палитры сохраняют переход в отфильтрованный каталог. Предпросмотр разных букетов по наведению в эту первую версию не включён.

## Проверено

npm run check; npm run build — 11 страниц. Проверены разметка и встроенный JS итоговой главной, ссылки на товар и каталог. Отдельная проверка сценария в имитированной DOM-среде: desktop, mobile, reduced motion, восстановленная прокрутка, фоновая вкладка, отсутствие WAAPI; очистка на переходах и отсутствие двойного старта.

Внешний вид и плавность в настоящем браузере здесь не проверены. После переноса оцените первое появление и прокрутку на компьютере и телефоне.

## Настройка

Длительности и задержки — src/scripts/hero-motion.ts. Последовательность прорисовки — data-flower-delay и data-flower-duration в HeroBotanical.astro. Основные размеры, цвет и положение рисунка — встроенный style в Hero.astro.
