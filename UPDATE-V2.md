# Обновление «Референс цветочного» до версии 2

В архиве — полный проект. Для обновления существующей папки не нужно заново устанавливать зависимости: package.json и package-lock.json не менялись.

1. Остановите старый dev-сервер через Ctrl+C.
2. Сохраните копию своей текущей папки src, если в ней есть собственные правки.
3. Распакуйте архив в отдельную временную папку. На верхнем уровне должны быть src, public и package.json.
4. Скопируйте папки src и public целиком в существующую flower-reference, согласившись объединить папки и заменить файлы. Нельзя перенести только Hero.astro: обновление использует новые CSS, SVG-компонент и скрипт.
5. При желании скопируйте README.md, DESIGN-NOTES.md и этот файл.
6. В PowerShell из папки flower-reference выполните:

```powershell
Remove-Item -Recurse -Force .astro -ErrorAction SilentlyContinue
Remove-Item -Recurse -Force node_modules\.vite -ErrorAction SilentlyContinue
npm run dev
```

7. Откройте адрес из терминала. На вкладке сайта нажмите Ctrl+F5.

Папки node_modules и dist из архива не требуются. Не вставляйте содержимое Hero.astro в index.astro: это отдельные файлы. Файлы компонентов, стилей и страниц должны сохранить свои пути.

## Если запускаете в новой папке

Следуйте установке из README.md: npm ci, затем npm run dev. Все изображения и шрифты уже в public.

## Что проверить после переноса

Посмотрите главную на компьютере и телефоне; ссылки палитр; фильтры и их сброс; добавление букета с вазой; количество и итоговую сумму в корзине; выбор даты; мобильное меню; закрытие диалогов по Escape.

TypeScript, 8 тестов, сборка 11 страниц, локальные ссылки и 22 HTTP-запроса к dev-серверу проверены. Скриншоты и клики в браузере рабочего окружения проверить не удалось, поэтому окончательное визуальное соответствие нужно посмотреть после переноса. Заказы и платежи по-прежнему демонстрационные.
