# Аккуратная визуальная доработка

## Установка

1. Остановите dev-сервер через Ctrl+C.
2. Распакуйте flower-visual-polish-v1.zip в отдельную папку.
3. Скопируйте папку src из архива в корень проекта flower-reference с объединением папок и заменой файлов. Существующую src удалять не нужно.
4. Запустите npm run dev в корне проекта.
5. Обновите страницу через Ctrl+F5.

Зависимости не менялись. CSS доработки находится в существующем src/styles/refinement.css; его уже подключает BaseLayout.astro. Стили hero остаются внутри Hero.astro.

## Что изменено

- Убраны надписи «ВЫБРАТЬ ЦВЕТЫ», «ДЕТАЛИ ЗАКАЗА», «ПОЛЕЗНО ЗНАТЬ» над соответствующими заголовками.
- Убраны линии над и под блоком индивидуального букета, рамка вокруг формы и линия над примером пожеланий. Поля формы сохраняют границы и состояние фокуса.
- Убраны границы по краям раздела дополнений: его выделяет собственный фон.
- Убрана линия перед предложением индивидуального подбора под каталогом.
- Доставка показана тремя открытыми колонками без общей рамки и вертикальных разделителей. На телефоне — три последовательных пункта с отступами.
- Заголовки доставки и FAQ компактнее. Перенос строки в заголовке доставки теперь определяется доступным местом.
- В FAQ сохранены разделители вопросов, но их цвет немного приглушён. Активная линия вкладок каталога сохраняется.
- Рамка за фотографией hero стала светлее. Сценарий hero-анимации не менялся.
- Отступы различаются по роли блока и адаптированы для компьютера, планшета и телефона.

Шапка, подвал, сами цветочки, фотографии, ассортимент, корзина и формы сохраняют прежнее поведение. Публикация, БД и CRM в это обновление не входят.

## Проверка

npm run check и npm run build прошли; собрано 11 страниц. Проверены якоря главной, наличие подключённых CSS, разметка hero и подвала. Контрольные суммы подтверждают, что код шапки, подвала, анимации hero, цветочного рисунка, каталога, корзины и данных товаров не менялся.

Внешний вид в настоящем браузере здесь не проверен. После установки оцените ритм главной на компьютере и телефоне.
